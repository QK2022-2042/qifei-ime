本轮需求变更（用户明确要求）
安装包必须自带当前推荐的大模型，第一次安装就有大模型可用；后续升级或下载其他模型完全由用户人工触发，程序不自动下载、覆盖安装也不能冲掉用户换过的模型。这推翻了此前「主包保持干净、模型单独补包」的设计，代价是安装包从 164.8 MB 增至 1207.7 MB。语音识别模型（SenseVoice，约 414 MB）仍按首次启动引导下载，与润色大模型是两回事。
累计抓到并修掉的三个硬缺陷
① 真机安装后服务端起不来：ModuleNotFoundError: No module named 'onnxruntime'。SenseVoice 走自定义 ONNX 引擎，依赖既没写进 requirements，也没被 PyInstaller 收集，旧自检还漏检成 PASS。
② 完整构建必失败、单目标却正常：三个 Analysis 共用 CONF['workpath']，PyInstaller 构造 base_library.zip 写死「先删再建」，后两个目标必然删前一个的文件，被环境的批量删除保护拦下。
③ 本轮新抓到：覆盖安装被运行中的输入法锁住。QifeiServer.exe 的 multiprocessing worker 会占着 exe，第一次覆盖安装直接 PermissionError: [Errno 13]、退出码 1，还留下「两个 exe 已更新、服务端仍是旧版」的半更新状态。修法见第四节。
