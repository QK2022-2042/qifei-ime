# 启飞输入法 使用说明

> 按住说，松开就有字。完全离线的中文语音输入。

启飞输入法是在 [CapsWriter-Offline](https://github.com/HaujetZhao/CapsWriter-Offline) 基础上二次开发的桌面语音输入工具：**说话即上屏**，语音不出本机，不联网、不上传。

---

## 一、安装

### 方式一：一键安装包（推荐）

双击 `启飞输入法-2.0.4-安装包.exe`：

1. 选择安装位置（默认 `%LOCALAPPDATA%\Programs\QifeiIME`，**不需要管理员权限**）
2. 点「立即安装」，等待进度条走完
3. 勾选「安装完成后立即运行」，或从桌面 / 开始菜单打开「启飞输入法」

安装包**已内置中文润色大模型**（`qwen2.5-1.5b-instruct-q4_k_m.gguf`，约 1.04GB）：装完第一次打开，「大模型」页就是 `llama.cpp 就绪`，不用下载、不用装 Ollama、不联网，润色角色直接可用。

**语音识别模型仍需下载**：首次启动引导第 3 步会下 SenseVoice 小模型（约 414MB），那是听写必需的，和润色大模型是两回事。软件本体约 320MB（大部分是自带的 llama.cpp 动态库），安装包约 1.2GB = 本体 + 内置模型。因为内置了 1.04GB 的润色模型，安装包体积主要来自模型，程序本体压不了多少；如果下载 exe 被杀毒软件拦截，改用桌面上的 `启飞输入法-2.0.4-安装包-压缩版.zip`（详见「常见问题」）。

以后想**升级或换别的大模型**，把新的 `.gguf` 拷进安装目录 `models\llm\`，或在「大模型」页点「选择模型文件（已下载好的）」人工导入；若内置模型文件损坏，也可在「大模型」页确认后重新下载内置版本（约 1.04GB，唯一需要联网的动作，确认框默认选「否」）。程序不会自动下载，覆盖安装、升级安装都不会冲掉你人工换过的模型；**打开一次「大模型」设置页也不会把它悄悄换回内置模型**——即使模型放在别的盘、没加进扫描目录，或在符号链接 / junction 的安装目录里，它都会作为「当前配置」保留在下拉框中。想让它每次自动出现，点「添加扫描目录」把所在目录加进来即可。「推理引擎」保持「自动（优先进程内）」就行，安装包自带 llama.cpp 动态库，不需要再装任何程序。

如果你改用「远程 API」或「本机 Ollama」后端：**打开设置页、切换后端、点「下载推荐润色模型」都不会把本机扫到的 `.gguf` 自动填进模型名，也不会覆盖你填的远程模型名**；选好的后端重启后会保持，不会被旧版本的默认后端迁移改回去。想用本地模型时把后端切回「直连 llama.cpp（推荐）」即可。

**2.0.4 起，远程后端有独立的「服务方模型名」输入框**：切到远程 API / Ollama 后，在那一栏填服务商给的模型名（例如 `deepseek-chat`、`qwen2.5:7b`），**不是**本地 `.gguf` 文件名；这一项只写 `llm.model`，不会动 `llm.model_path`。远程 API 后端不再显示本机 `.gguf` 下拉框（避免误点把模型名冲成 GGUF 文件名），Ollama 后端仍保留本地文件列表用于「导入到 Ollama」。没填服务方模型名就点「测试连接」会明确提示去哪一栏填，不会再让你去选本地模型文件。

### 方式二：绿色版

把 `dist\QifeiIME` 整个文件夹复制到任意位置，双击 `QifeiIME.exe` 即可。

### 卸载

开始菜单 →「卸载启飞输入法」，或 设置 → 应用 → 启飞输入法 → 卸载。
卸载会保留 `%APPDATA%\QifeiIME` 下的配置与录音，需要彻底清理可手动删除。

## 三、怎么用

### 三种说话方式

| 操作 | 效果 |
| --- | --- |
| **按一下 Tab** | 开始录音；**再按一下 Tab** 结束并上屏 |
| **按住空格** | 按住说话，松开立即结束并上屏 |
| **录音中按空格** | 暂停录音；再按一下继续，整段合成一句话 |
| **按住鼠标侧键 X2** | 同空格，适合右手不离鼠标 |

### 关于空格

空格既是「按住说话」键，也仍然是普通空格：

- 按住超过 0.25 秒 → 当作录音
- 轻点（< 0.25 秒）→ 取消录音，并原样补发一个空格

所以正常打字不受影响。如果觉得空格输入有延迟感，可在 **设置 → 快捷键 → 触发灵敏度** 把阈值调小（如 0.15 秒）。

### 悬浮状态条

录音时屏幕底部中间会浮出一个小胶囊：

- 蓝色声波 +「正在聆听」= 正在录音
- 橙色 +「已暂停」= 已暂停，再按空格继续
- 「正在识别」→「已上屏」= 本次结束

不想看到它可以在 设置 → 启动与常驻 里关掉。

## 四、语音模型

模型完全离线运行。**语音模型第一次使用需要下载**（润色大模型已随安装包内置，不用下）；安装包不带语音模型，原因很简单：最准的引擎有 1.8 GB，而大多数人用不上。

| 引擎 | 体积 | 特点 | 适合 |
| --- | --- | --- | --- |
| SenseVoice 小模型 | 约 414 MB | 启动快、占用小，中英日韩粤 | 日常听写（推荐） |
| Paraformer | 约 488 MB | 纯 CPU 最快 | 老电脑 |
| Fun-ASR-Nano | 约 796 MB | 准确率与速度平衡 | 办公记录 |
| Qwen3-ASR 1.7B | 约 1.86 GB | 最准，长句表现好 | 有显卡、追求准确 |

### 下载方式

**设置 → 语音模型 → 选择引擎 → 下载并安装**。支持断点续传，中途取消下次会接着下。

国内网络慢可以切到「国内加速镜像」。

### 自定义模型路径

模型可以放在任意磁盘（比如空间更大的 D 盘）：

1. 设置 → 语音模型 →「更改目录」，选择目标文件夹
2. 之后下载的模型会落到这个目录

如果已经有现成的模型目录（例如原来的 CapsWriter-Offline），直接指过去即可，程序会自动识别其中可用的引擎。

目录结构约定：

```
<模型根目录>/
├── SenseVoice-Small/Sensevoice-Small-ONNX/...
├── Paraformer/speech_paraformer-large-.../...
├── Fun-ASR-Nano/Fun-ASR-Nano-GGUF/...
├── Qwen3-ASR/Qwen3-ASR-1.7B/...
└── Punct-CT-Transformer/...          # Paraformer 需要
```

## 六、常见问题

**Q：下载安装包时被杀毒软件 / 浏览器拦截了？**
从 2.0.4 起提供 `启飞输入法-2.0.4-安装包-压缩版.zip`：下载和传输阶段拿到的是压缩包，先解压再双击里面的 exe，能避开对「直接下载无签名 exe」的即时阻断。包里附 `SHA256SUMS.txt` 和《校验与安装说明》，**先核对哈希再运行**。
这是启发式误报，不是包里有恶意文件：安装器是 PyInstaller 打包的未签名自解压程序，运行时会解压到系统临时目录、结束正在运行的旧版输入法（`taskkill`）、用 PowerShell 建快捷方式、写 HKCU 卸载项并生成卸载脚本。安装包内容已做只读体检，payload 里只有程序本体、运行时 DLL、随包资源和内置模型，没有日志 / 缓存 / 备份 / 临时文件，Setup.exe 内嵌的 payload.zip 与构建产物逐字节一致。确认哈希无误后可加入杀软白名单；根治需要有效的代码签名证书。

**Q：按 Tab 没反应？**
先看托盘图标提示与「概览」页状态。如果显示「听写未运行」，点设置里的「重启听写服务」。
在管理员权限运行的程序（任务管理器、部分游戏）里输入，需要用管理员权限运行启飞输入法。

**Q：说了话但没出字？**
1. 概览页看「模型已就绪」是否正常
2. 听一下录音文件，确认麦克风有声音
3. 检查 Windows 设置 → 隐私 → 麦克风，允许桌面应用访问

**Q：模型加载很慢 / 一直加载中？**
大模型首次加载要几十秒到几分钟（取决于硬盘与内存），期间状态是「模型加载中」。超过 3 分钟仍未就绪，多半是模型文件不完整，重新下载一次。

**Q：空格打字变得有点慢？**
这是「按住说话」的固有代价：程序要先确认你是轻点还是按住。把触发灵敏度调到 0.15 秒会明显改善；或者干脆关掉空格，只用 Tab。

**Q：和讯飞输入法冲突吗？**
不冲突。启飞输入法是独立的后台程序，不注册输入法框架，两者可以共存。但如果你在讯飞里也设了同一个快捷键，会互相抢按键。

**Q：能多台电脑共用模型吗？**
可以。把模型目录放在移动硬盘或网络盘，在每台电脑的「语音模型 → 更改目录」里指过去即可。

## 七、开发者

### 目录结构

```
qifei_ime.py         图形界面入口
qifei_client.py      听写客户端入口
qifei_server.py      识别服务端入口
qifei/               界面代码（主题、向导、设置、悬浮条、进程托管）
core/client/         客户端核心（快捷键、音频、上屏、热词、LLM）
core/server/         服务端核心（模型加载、推理、标点）
config_client.py     客户端默认配置（可被 JSON 覆盖）
config_server.py     服务端默认配置
config_override.py   JSON 配置覆盖层（%APPDATA%\QifeiIME\config.json）
build/qifei.spec     PyInstaller 配置
build/build_all.py   构建脚本
installer/           一键安装包（内置 payload.zip 的引导安装器）
tests/               录音交互回归测试
```

### 从源码运行

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements-gui.txt -r requirements-client.txt -r requirements-server.txt
.venv\Scripts\python qifei_ime.py
```

### 跑测试

```bash
.venv\Scripts\python -m pytest tests -q
```

### 打包

```bash
.venv\Scripts\pip install -r requirements-build.txt

python build\build_all.py                 # 界面 + 客户端 + 服务端
python build\build_all.py --target gui    # 只打界面，快速验证
python build\build_all.py --installer     # 打完再生成一键安装包
```

产物：

```
dist/QifeiIME/                         可分发目录
dist/启飞输入法-2.0.4-安装包.exe        一键安装包
```

### 自检与静默安装

打包后的三个程序都带自检开关，出问题时先用它定位：

```bash
QifeiServer.exe --selftest   # 检查推理库、模型目录，以及当前引擎的模型权重是否齐全
QifeiClient.exe --selftest   # 检查麦克风、快捷键、上屏依赖
```

输出末尾会打印 `SELFTEST PASS` 或 `SELFTEST FAIL(n)`。服务端自检除 `numpy` / `soundfile` / `sherpa_onnx` / `websockets` 外，还会核对 SenseVoice 引擎真正用到的 `onnxruntime` / `sentencepiece`，并按当前 `model_type` 检查模型文件是否齐全——依赖装了但没下载语音模型也会明确 FAIL，不会误报 PASS。

安装包支持无人值守安装（批量部署用）：

```bash
启飞输入法-2.0.4-安装包.exe --silent --dir "D:\Apps\QifeiIME" --no-launch
```

**覆盖安装前会自动结束正在运行的输入法**（托盘主程序、听写客户端，以及 `QifeiServer.exe` 的 multiprocessing 子进程）：这些进程会锁住 exe，不清理会出现「文件被占用」并留下半更新状态。图形安装与 `--silent` 两条路径都先清理、等句柄释放，再覆盖文件；结果同时写进安装目录下的 `install.log`。

### 打包注意事项

- PyInstaller 必须 **6.11 及以上**：6.9 的 bootloader 不认 Python 3.13，打出来的 exe 会直接段错误退出。
- `build_all.py` 每次构建都用独立的 `--workpath`，并且把旧产物改名到 `.tmp/trash` 而不是删除。`build/qifei.spec` 里三个 `Analysis` 也各有独立工作子目录：PyInstaller 构造 `base_library.zip` 时会写死「先删再建」，共用一个目录时后两个目标会删掉前一个留下的文件，在禁止删除的受管控机器上完整构建会直接失败（单目标构建却正常）。这样改从根上避免覆盖删除。
- **安装包内置推荐润色模型**：`build_all.py` 把 `models/llm/qwen2.5-1.5b-instruct-q4_k_m.gguf` 复制进绿色版，`installer/build_installer.py` 只放行这一个 `models/` 条目（`logs`、ASR 权重、下载缓存都不进包），并对它用 `ZIP_STORED`——GGUF 已量化，deflate 压不动还白等几分钟。想回到「主包不带模型」的小包策略，构建时设 `QIFEI_BUNDLE_MODEL=0`。
- **覆盖安装不冲掉用户模型**：`installer/installer_app.py::extract_payload()` 对 `models/` 下已存在的文件一律跳过，程序本体照常覆盖。用户以后人工换的、升级的、下载的其他 `.gguf` 都原样保留；GUI 与 `--silent` 两条安装路径共用这段逻辑。`stop_running_apps()` 会在解压前用 `taskkill /F /IM` 结束运行中的输入法，避免 exe 被锁；`extract_payload()` 还对 `PermissionError` 做一次等待重试，失败时给出可照做的中文提示。
- 服务端用的是自定义 ONNX 引擎（`core/server/engines/sensevoice_onnx`），`onnxruntime` / `sentencepiece` 由 `build/qifei.spec` 用 `collect_submodules` / `collect_dynamic_libs` / `collect_data_files` 显式收进 `QifeiServer.exe`；这两个库漏打包时，模型检查会通过但识别子进程会直接退出，真机上踩到过。自检和发版核对都会检查它们。
- 可选的独立模型补包：跑 `python tools/make_llm_model_pack.py` 生成 `dist/启飞输入法-LLM润色模型包.zip`（约 1.04GB），用于给旧版本补模型或离线换一个模型；`--check` 只校验 CRC。新安装包已自带模型，正常安装不需要它。
- 出完包跑一次 `python tools/verify_release.py` 核对分发产物：检查 `dist/` 没有旧产物叠加、**payload 恰好内置一份推荐模型且大小 / 魔数 / 名字都对**、服务端推理库确实随包、Setup.exe 内嵌内容与源文件一致、安装器代码是新版（含用户模型保护与 `stop_running_apps`），并在临时目录模拟全新安装 + 覆盖安装，验证首次装完有模型、用户换过的模型不被冲掉。它**不会真的运行安装器**，不写桌面 / 开始菜单 / 注册表；输出 `RELEASE_VERIFY_OK` 才算通过。

### 改名

品牌信息集中在两处，改完重新打包即可：

- `qifei/brand.py`：界面显示名、版本、标语
- `config_override.py` 的 `APP_ID`：配置目录名（`%APPDATA%\<APP_ID>`）
